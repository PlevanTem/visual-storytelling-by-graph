# 专门方法与边缘任务

这些表达用于回答特定问题，不是“高级图表”通用升级路径。默认先确认数据前提；给出简单替代。画廊中的数据全部为合成模拟，不能解释为真实行业发现。

## 组成：三元图 / C13

- 三项非负且共同构成同一整体，和为 100%。点位置为三顶点的加权和：P=aA+bB+cC，a+b+c=1。
- 本例顶点为 Clay（上）、Silt（左）、Sand（右）；网格沿三边读比例。不能把闭合分量当成相互独立的因果变量。
- 图用于看混合与聚类。精确查值可用表格；没有领域分类依据就不添加分类边界。
- 分组切换保留三角形与尺度，仅过滤样本并同步 n。

## 周期方向：面积归一的风玫瑰 / C14

- 已知观测方向与速度档；本例按数据约定表示“来自何方”，由北顺时针。
- 等角扇区，r=sqrt(kN)；环带面积与分档次数成比例。刻度也必须按平方根映射，不能画线性半径却宣称面积正比。
- 分母是全部 240 次非静风观测；排除的无方向观测必须披露。颜色与图例明确速度档。
- 对精确交叉比较，可改为方向×速度矩阵。这个面积编码是本项目设计，不代表所有风玫瑰采用同一尺度。

## 右删失：Kaplan–Meier / C15 [S08]

- 每对象有时间、事件指示和分组。未发生事件但结束观察是删失，不是失败，也不是无限寿命。
- 每个事件时刻 t，风险集 n 为 time≥t 的对象；事件 d，S(t)=S(t−)*(1-d/n)。同一时刻的事件与删失都进入该时刻风险集，之后移除。
- 阶梯只在事件时刻下降；删失以记号表示。显示风险集，曲线止于各组最后观察；不在无覆盖区间外推。
- 独立、非信息性删失是解释前提。没有区间估计方法与数据，不补造置信带；组间不同也不自动证明环境因果效应。
- 本例是档案材料耐久，不是临床结论或寿命预测。

## 配对方法一致性：Bland–Altman / C16 [S09]

- 同对象两种方法、同单位。横轴为两者均值，纵轴为 B−A。
- 偏差为差值均值；描述性一致性界限为均值±1.96×样本 SD。本例使用 n−1 的样本方差。
- 一致性界限不同于均值置信区间，也不同于预先给定的 ±3 dB 实际容许差异。
- 约 95% 的解释需要相应分布和方差假设；小样本、异方差或差值趋势时须重新建模。高相关不证明可替换。本例未证明模型假设，界限只作描述展示。

## 精确集合交集：UpSet / C17 [S07]

- 原始对象 ID 唯一，成员向量明确。列表示一个精确成员模式：选中集合内、未选中集合外。
- 所有精确交集互斥，列计数之和等于定义总体。包含交集则允许额外标签，不能与精确交集混称。
- 本例总体仅含至少一个标签的物件；0000 不在此总体。“至少两标签”筛选后同步对象总数和模式数。
- 当集合数量大、模式过多时，排序、聚合与检索由任务决定，不静默删除不便显示的交集。

## 真实对象转移：Alluvial / C18

- 每对象有完整阶段序列。相邻阶段按实际记录汇总边权，带宽=计数×共同尺度。
- 本例节点输入输出与阶段总数守恒；若真实数据有加入、退出或损耗，应增加明确节点，而非强制抹平。
- 布局影响交叉数量，但不能改变边权。多个细流不适合精确比较时提供转移矩阵。
- 记录描述迁移，不识别原因。

## 时间×时间的相近状态：递归图 / C19 [S11]

- 本例只在标量幅度空间比较：Rij=1 当且仅当 |xi−xj|≤epsilon；嵌入维度为 1。
- 对称、对角线必为 1。递归率分母排除对角线：sum(i≠j)Rij / [n(n−1)]。
- epsilon 的单位与数据相同，切换阈值时不重新归一化。提高 epsilon 不会减少递归点。
- 纹理依赖阈值、度量、采样、趋势和嵌入选择；本例不重建隐藏相空间，也不证明混沌或机制。

## 压缩正负时序：Horizon / C20 [S10]

- 同一零参考、每带 2°C、共 3 带；负值向上镜像，蓝色表负，琥珀色表正。
- 每带高度由 clamp(|v|−2k,0,2) 映射，逐带叠加；不是多条独立序列。
- 共享带宽与色阶支持比较变化时段，精确读值仍需明细或普通折线。超过 6°C 必须标记或扩展，不能静默裁剪。
- 本例连续密度和视觉压缩是设计选择，不能直接泛化为所有读者更易理解。

## 多值响应：循环相轨迹 / C21

- 以采样顺序连接输入与响应，并标记方向或步骤；同输入可能存在多个响应。
- 不把相同输入平均成单一函数，也不将回路自动解释成某种物理机制。
- 本例是归一化示意，非拟合材料定律。若真实采样不连续，应保留断点。

## 分布与带宽：山脊 KDE / C22

- Gaussian KDE：f(x)=sum exp[-(x−xi)^2/(2h²)] / [n*h*sqrt(2*pi)]。
- 所有组同一横轴、绝对密度尺度和当前带宽 h；每组样本量明确。不对每条曲线单独撑满高度。
- h=2/5/10 NTU 仅改变估计外观，不改变观测数据。密度不是点概率；单位为 1/NTU。
- 当前绘制 [0,100]，尾部未重新归一化；不据平滑形成的峰自动断言存在真实子群。

## 重复值与尾部：蜂群 / C23

- 横坐标必须等于原始值；只沿纵向避碰。位移不编码其他变量。
- 三组均值相同仍可能具有不同模态、尾部与中位数。原始点、样本量和极值保留。
- 点数太多时可改点阵、ECDF 或透明散点，不能通过水平抖动改变精确等待时间。

## 时频：STFT 幅度谱 / C24 [S12]

- 采样率 128 Hz；64 点对称 Hann 窗；步长 16；不额外补零，只用完整窗口。
- 横轴为窗口中心，纵轴 k*fs/N。显示 20log10(|DFT|/全图峰值)，下限 −50 dB。
- 这是相对幅度，不是 PSD；不同参考或窗口不能直接混比。时频分辨率存在权衡。
- 固定频率与扫频来自已知合成输入，不据纹理识别真实声源。

## 画廊交互

原始数据、计算、设计与下载不靠悬浮才可见。参数切换同步图、单位、方法和摘要；导出绑定当前状态。支持键盘、关闭展览、前后切换及减少动态效果。沉浸式画廊不能代替可读的静态图。
