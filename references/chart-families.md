# 图表族与切换条件

以任务检索。这里是条件性工程参考 [R04, R05]，不是已实现组件清单；工具能力须单独核实。

| 任务 | 候选 | 前提与编码 | 切换条件／误用 |
|---|---|---|---|
| 精确查值 | 表格、直接数值 | 单位、口径、排序 | 模式发现再加图；面积不替代读数 |
| 大小与排名 | 排序点图、条形 | 类别×可比度量；位置／长度 | 有自然顺序则保序；多类别可检索，不能静默删尾部 |
| 距目标差距 | 子弹图、偏差点图 | 实绩与同单位目标 | 多目标可分面；解释目标来源 |
| 前后变化 | 哑铃、配对线、变化点图 | 同对象两时点 | 独立样本改用分布／区间；连线不表示中间轨迹 |
| 时间趋势 | 线、阶梯、小多图 | 真实时间与测量语义 | 离散变更可阶梯；缺测断开；不伪装等间隔 |
| 多条时序 | 小多图、热图、概览+细节 | 相容时间轴与尺度策略 | 查单条用细节；颜色不适合精确微差 |
| 构成 | 堆叠、100% 堆叠 | 互斥、可加、共同整体 | 总量用普通堆叠；中间分量精确比较改用分面 |
| 少量部分整体 | 条形、饼／环 | 非负、同一整体 | 接近值、多项、负值改用位置；非互斥项不是一个饼 |
| 增减贡献 | 瀑布、发散条 | 起点+有符号贡献=终点 | 加和不成立不强凑；贡献块不是独立总量 |
| 分布 | 直方、ECDF、点阵 | 观测值或明确频数 | 检查分箱敏感性；小样本保留点，慎用平滑 |
| 分组分布 | 箱线+点、小提琴、ECDF | 可比样本、摘要定义与 n | 箱线隐藏多峰；小提琴依赖密度估计 |
| 两变量关系 | 散点、hexbin、密度 | 同观测的数值对与单位 | 密集先聚合／透明；抽样不静默抹掉异常；回归不证明因果 |
| 多变量比较 | 散点矩阵、平行坐标、分面 | 量纲与缩放 | 精确比较常用分面；雷达形状依赖轴序 |
| 迁移 | alluvial、转移矩阵 | 同对象路径或转移量 | 只有阶段总量不足；精确边权可用矩阵 |
| 流量 | Sankey、边权表 | 节点、边、单位、时期、损耗 | 不假定自动守恒；负流、环路需方法与工具支持 |
| 层级 | 缩进树、树图、treemap | 真实父子关系与可加量 | 查结构用树；面积看构成，微差用条形 |
| 网络 | 邻接矩阵、节点连线 | 有意义的节点与边 | 稠密可用矩阵／局部；布局距离不是业务距离 |
| 地理 | 点地图、分级设色、分面 | 空间本身重要、边界口径匹配 | 只是类别则排序图；区分数量、人均和率 |
| 不确定性 | 点区间、森林图、带状图 | 估计量、区间类型、水平、方法 | CI、SD、SE、预测区间不混用；含零不证明无效 |
| 重复测量 | 个体轨迹+摘要 | ID、时间与缺测处理 | 过密可分面或披露抽样；总体不替代个体 |

## 精细判断

### ECDF 或分位数点图

ECDF 的横轴为测量值，纵轴为不大于该值的比例，使用阶梯。适合尾部、阈值覆盖和分布交叉。分位数点图适合快速比较，但必须固定分位数算法。只有均值不能恢复分布。示例：`examples/charts/02-latency.svg`，数据：`evals/fixtures/latency.json`。

### 配对变化

同一对象连线，共同纵轴；定义“后−前”和改善方向。说明完整配对数与缺失人数。没有对照的前后测不自动识别因果。线过密可用变化分布或高亮。示例：`examples/charts/03-paired.svg`。

### 分组与总体率

保留分子分母。总体率按分子分母合计重算；组内与总体可能反向。描述实际总体与控制构成后比较是不同任务。切换分组同步标题、样本与摘要。示例：`examples/charts/04-conversion.svg`。

### 缺测时序

按实际时间间隔定位；显式 null 与超过采样约定的间隙断开。样本超阈比例不是持续超阈时间。插值需要方法说明与可见区别。示例：`examples/charts/05-sensor.svg`。

### 点区间

点为估计，线为注明类型的区间。差值参考 0，比值常参考 1；是否使用对数需任务与数值支持。不要将含零写成证明无效，也不凭两个区间是否重叠代替对应检验。示例：`examples/charts/07-uncertainty.svg`。

### 类别很多

找异常用排序与检索；完整覆盖用全量表格或可滚动视图。Top N 说明依据、覆盖和其他项口径，不把正负变化混在“其他”里掩盖。阈值依屏幕与任务，不硬设“超过七类一律禁用”。

## 科学工程专用表达 [S01]

Origin 提供丰富的科学制图参考，专用图需要领域语义。

| 表达 | 先确认 |
|---|---|
| 等值线／热图／曲面 | 网格、插值、单位、缺失及是否需要第三维 |
| 三元图 | 非负组成、共同整体、归一化与闭合含义 |
| 极坐标／风玫瑰 | 循环语义、方向、频率与幅度 |
| 向量／流线 | 坐标系、分量、空间采样与插值 |
| Q-Q／概率图 | 参考分布、样本量、尾部解释 |
| 控制图 | 过程、子组、控制限与稳定性；控制限不同于规格限 |
| Bland–Altman | 同对象两方法、差值、偏差与一致性界限假设 |
| 生存曲线 | 事件、起点、删失、风险集 |

本包未实现或验证全部专用图。遇到此类任务，核实方法和工具原始文档后，交付能够验证的实现。
