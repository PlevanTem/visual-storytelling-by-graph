# 叙事、交互与视觉设计

## 谁控制阅读 [R03]

解释任务可引导顺序，探索任务允许读者提出不同问题。可选静态注释、逐步展开、交互幻灯片、先引导后探索、或以探索为主的注释视图。叙事框架不是保证理解或说服的公式。

简短计划可包含：问题→必要背景→主要证据→重要差异→限制→行动含义。没有依据的部分留空。先分析数据，不按期待标题挑选支持片段。

标题强度示例：“样本 p95 上升”是可核算事实；“尾部变慢，同时中位数下降”是有限解释；“新版改善所有用户体验”可能被分布交叉推翻。总体与分组方向相反时说明比较口径。

## 版面承担阅读顺序 [R06]

- 一个主任务一个主要焦点；必要的相邻视图支持它，不堆满等权卡片。
- 标题回答问题或定义范围，副标题给对象、时期和单位，页脚给来源与必要处理。
- 依据大小、时间、阶段或业务顺序排序，不为装饰换位。
- 用对齐、距离、共同尺度建立比较。独立尺度看形状时，说明不能直接比绝对幅度。
- 直接标签减少图例往返；密集情况保留关键标签并给可查明细。
- 色彩表达类别、顺序、方向或焦点；同对象跨图同色。顺序量不随意使用彩虹。
- 焦点色只给重点，其他信息降低饱和度；结合位置、文字或线型，不只靠颜色区分。
- 减少装饰边框，保留有助估值的网格与参考线。极简不能删必要分母、区间或来源。
- 字号与密度按实际输出尺寸检查；桌面图整体缩小不等于手机适配。
- 静态导出保留主要发现和限制，必要时另排导出版。

这些是工程规范，未经过本项目读者实验校准，不宣称统一审美标准。

## 每个交互都有合同 [R07]

| 读者任务 | 可选操作 | 同时设计 |
|---|---|---|
| 找对象 | 搜索、选择、高亮 | 命中、未命中与清除 |
| 排除无关对象 | 筛选 | 当前范围、分母、n、空结果、复位 |
| 比较排序／布局 | 排序、重组 | 稳定身份、依据和方向 |
| 改指标／口径 | 编码或单位切换 | 轴、标题、单位、图例与结论 |
| 看粒度 | 明细展开、钻取 | 层级、返回路径、聚合规则 |
| 找关联 | 跨图联动 | 全部关联视图与取消选择 |
| 看局部 | 缩放、概览+细节 | 范围、全局定位与恢复 |
| 查敏感性 | 情景参数 | 假设、输入范围、结果属性 |

### 按需使用的注释

- “合成演示数据，非真实业务结果。”
- “总体率按成功数合计／样本数合计计算。”
- “按真实时间定位；缺测与超出约定采样间隔的断点保留。”
- “线段为输入提供的 95% 置信区间，本图未重新估计。”
- “仅连接同一对象，前后变化不构成因果证据。”

只选当前任务必要的说明，不把全部注释堆进每张图。
