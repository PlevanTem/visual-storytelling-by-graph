# 意图、数据与路由

## 最小充分信息 [R01]

用一句话复述：谁，在什么场景，需要用这些数据回答什么问题？
“销售可视化”不够具体；“周会上找到最近一月收入下降最多且样本可靠的门店”可以转成任务。金额下降、下降比例和目标缺口不能互相替代。

| 信息 | 判断问题 | 设计影响 |
|---|---|---|
| 读者与场景 | 专业背景、阅读时长、设备、使用频率？ | 密度、术语、默认视图 |
| 问题与目的 | 查值、比较、异常、解释还是选择？ | 表格／单图／多图及顺序 |
| 行动 | 看完后需要做什么？ | 阈值、基准、优先级 |
| 数据粒度 | 每行是人、事件、订单还是汇总地区？ | 计数、配对、合法聚合 |
| 度量语义 | 存量、流量、率、指数还是估计？单位？ | 变换、尺度、标签 |
| 可比性 | 时间窗口、分母、覆盖、样本一致吗？ | 能否直接比较 |
| 证据 | 观测、推断、实验估计还是预测？ | 标题强度、区间、边界 |
| 交付 | 静态、打印、演示、手机、桌面分析？ | 尺寸、交互、降级 |
| 成功 | 读者应回答哪两个具体问题？ | 验收任务 |

别机械问完。关键分母、时间或配对信息缺失会造成错误时才先问；可先做不依赖答案的部分。可逆视觉偏好以合理假设推进。

## 数据检查 [R02]

读取实际数据并保留原文件；确认对象、时间和单位；检查重复主键、缺失、覆盖、极值和单位混用；记录变换公式、权重、分母与筛选；抽查原始记录和汇总结果。无法确认的语义保留为未知。

- 合并率 = 分子合计 / 分母合计，不能默认平均各组比率。
- 20%→25% 为 +5 个百分点，相对增长 25%，写清口径。
- 月末余额不应像月收入一样逐月相加。
- 累计曲线上升不表示当期表现持续改善。
- 同对象前后测可以计算个体变化；不同对象不能伪造配对。
- 需求总量用于容量规划，人均量用于强度比较，没有通用优先级。
- 零是观测；缺失可能是无覆盖、未上报或不适用。
- 完成者、留存者或已上报样本不自动代表完整总体。

## 用途路由 [R01, R03]

| 目的 | 默认组织 | 重点检查 |
|---|---|---|
| 查值 | 数值或带单位表格 | 排序、总计、可核对性 |
| 解释 | 主要发现及必要证据 | 结论强度、反例、阅读路径 |
| 探索 | 可读默认视图与探索入口 | 粒度、筛选状态、明细 |
| 监控 | 状态、阈值、时间与异常 | 新鲜度、缺测、报警口径 |
| 诊断 | 总体→子群→候选解释 | 基准、构成、尾部、混杂 |
| 决策 | 选项、约束、证据与权衡 | 量纲、敏感性与未知项 |

## 候选选择 [R04]

先检查数据前提、合法计算和交付能力，再比较任务适配、精度、信息保留、理解成本、空间、交互和实现成本。写“好／可接受／有问题 + 原因”即可；权重依当前任务，不预置万能总分。

例：比较尾部延迟时 ECDF 保留分布，分位数点图方便快速阅读；只有平均值的柱形图遗漏主要任务。若高管只需快速判断 SLO，标注 p95、超阈率和样本量的简图可能更合适，ECDF 并非永远最优。

## 表格、补数与技术

少量精确数值、对账、多字段查找优先考虑表格。多个数字只支撑一句事实时可直接陈述。缺少必要转移、样本、分母或时间信息时，完成能完成的部分，并列出最小补数需求。

先检查已有工具。科学静态图用可重复渲染与导出的工具；交互探索用已支持的网页或 BI；版面叙事可组合 SVG 与文本。沿用项目约束，只有必要任务无法满足时才扩充依赖。

规则与证据边界见 [来源索引](sources.md)。
